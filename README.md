# Aplicação Web de Cadastro de Jogos

Projeto desenvolvido para a disciplina de Tecnologias Web, consistindo em uma aplicação web para cadastro e gerenciamento de uma coleção pessoal de jogos.

## 👥 Integrantes

|------|-----------------|
| Lucca di Stefanno | Página inicial (index.html) e estilização (style.css) |
| Davi Marques | Página de listagem (listagem.html) e lógica da aplicação (app.js) |
| Iury de Matos | Página de cadastro (cadastro.html) |

## 📋 Funcionalidades

- Cadastro de jogos com título, gênero, plataforma, ano, nota, desenvolvedora e descrição
- Validação de formulário com mensagens de erro
- Listagem dinâmica dos jogos cadastrados
- Busca por título, gênero, plataforma ou desenvolvedora
- Remoção de jogos da coleção
- Estatísticas da coleção na página inicial
- Dados persistidos entre páginas via localStorage

## 📁 Estrutura do Projeto
```
projeto/
├── index.html
├── cadastro.html
├── listagem.html
└── src/
├── style.css
└── app.js
```
## 🚀 Como executar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
3. Interaja com o site, faça cadastro de jogos e veja os seus jogos salvos!

## 🛠️ Tecnologias utilizadas

- HTML5 semântico
- CSS3 com variáveis e Flexbox
- JavaScript puro (Vanilla JS)
