## 🚀 O que foi desenvolvido recentemente?

Nesta etapa (desenvolvida através da branch `iury`), evoluímos o projeto inserindo um fluxo completo, validado e seguro para o registro de novos jogos no nosso catálogo iterativo!

### 📝 1. Nova Tela de Cadastro (`cadastro.html`)
- **Estruturação Robusta:** Um formulário acessível abordando os dados cruciais: *Título, Gênero, Plataforma, Ano, Nota, Desenvolvedora e Comentário*.
- **HTML5 Semântico:** Arquitetado desde o início priorizando as melhores práticas estruturais (`<header>`, `<nav>`, `<main>`, `<section>`, `<fieldset>`).

### 🛡️ 2. Validações Inteligentes (Front-end)
- **Prevenção de Erros:** Um script JavaScript interativo inspeciona os atributos vitais e proíbe o envio caso as regras sejam quebradas.
- **Feedback Guiado:** Caso o usuário acabe deixando alguma informação importante passar, são exibidas mensagens de erro amigáveis exatamente abaixo do campo precisando de correção.

### 🔗 3. Integração com o Estado Global
- **Salvar & Atualizar:** Conexão nativa e impecável com a função `addGame(game)` (presente no escopo global da base do projeto).
- **Micro-interações:** Nada melhor que ver uma ação finalizada, não é? Inserimos uma notificação de sucesso moderna (o famoso **Toast**) 🟢 *"✔ Game cadastrado com sucesso!"*, que aparece após concluir o pedido.

### 🌳 4. Gerenciamento com Git
- Todo o ciclo dessa feature foi cautelosamente guiado por commits organizados dentro de uma nova *branch* (`iury`), mesclada progressivamente junto com as atualizações da `develop`.

---

## 🛠️ Como Executar

É super rápido testar no seu ambiente local:

1. Acesse o diretório `cadastro_jogos`.
2. Dê dois cliques em **`index.html`** ou **`cadastro.html`** para abrir *direto* em qualquer navegador (Google Chrome, Firefox, Edge).
3. **Dica:** Se estiver usando o VS Code, sinta-se à vontade para apertar no botão <kbd>Go Live</kbd> do **Live Server** para rodar a aplicação em um servidor de desenvolvimento.
