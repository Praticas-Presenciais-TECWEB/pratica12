# Aplicação Web de Cadastro de Jogos

Projeto desenvolvido para a disciplina de Tecnologias Web.

## 👤 Integrante

Lucca di Stefanno

## 📋 Responsabilidades

- Página inicial (`index.html`)
- Estilização geral da aplicação (`style.css`)

## 📁 Arquivos da branch
```
projeto/
├── index.html
└── src/
└── style.css
```
## 📄 Descrição

A página inicial exibe as estatísticas da coleção de jogos, como total de games cadastrados, gêneros diferentes, nota média e último game adicionado. O `style.css` é compartilhado entre todas as páginas da aplicação, definindo o layout, cores e responsividade do projeto.

## 🛠️ Tecnologias utilizadas

- HTML5 semântico
- CSS3 com variáveis e Flexbox
